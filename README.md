# 发票 PDF 合并工具

报销打印辅助工具：将多个发票 PDF 合并为一个 PDF，可指定合并为一页或多页（网格排版、等比缩放、A4 纵向直接打印）。

## 使用方法

1. 双击 `run.bat`（首次运行会自动创建虚拟环境并安装依赖，需联网）
2. 拖拽（或点击“添加文件”）加入多个发票 PDF
3. 填写目标页数 n（例如 4 张发票合并为 2 页就填 2）
4. 点击“生成合并 PDF”，文件默认输出到桌面

## 输出规则

- 文件名：`m合n-date.pdf`，如 2 个文件合并为 1 页 → `2合1-2026-10-11.pdf`
- 输出目录：默认桌面（自动检测 OneDrive 桌面重定向），界面可修改
- 重名自动追加序号：`2合1-2026-10-11 (1).pdf`
- 多页发票：每个源文件的所有页都参与合并（文件个数 m 不变）
- 源页总数少于 n 时，按每页一张生成（实际页数 = 源页总数）

## 智能排版规则

工具根据每页条目数 k 与源页面平均宽高比自动选择行列布局，恰好占满、无空格、对称：

| 每页条目数 k | 布局 | 示例 |
|---|---|---|
| 1 | 整页 | 1合1 |
| 2、3 | 单列上下堆叠 | 2合1、3合1 |
| 4 | 2行2列 | 4合1 |
| 5（素数） | 单列堆叠 | 5合1 |
| 6 | 2列3行 | 6合1 |
| 9 | 3行3列 | 9合1 |
| 12 | 3列4行 | 12合1 |

- n>1 时同样适用，如 4合2 每页上下堆叠 2 张
- 源页面为极端宽高比（很宽或很窄）时，自动改选纸面利用率更高的转置布局（如窄长票据 2合1 会左右并排）

## 技术栈与架构

### 技术栈

| 类别 | 技术 | 说明 |
|---|---|---|
| 语言 | Python 3.10+ | 纯 Python 实现（使用了 `str \| None` 类型注解语法） |
| PDF 处理 | PyMuPDF (pymupdf) | 矢量级页面合成：`show_pdf_page` 以 XObject 引用方式放置源页面，保留文字/线条矢量清晰度，不转位图，速度快、文件小 |
| GUI | Tkinter（标准库） | 桌面窗口、文件列表、输入校验，零额外安装 |
| 拖拽 | tkinterdnd2 | 可选依赖，为 Tkinter 提供 OS 级文件拖放；缺失时自动回退为文件选择对话框 |
| 打包 | PyInstaller | `-F -w` 单文件无控制台 exe，`--collect-all` 收集 tkinterdnd2 的 Tcl 扩展与 pymupdf 资源 |

### 架构

```mermaid
flowchart LR
    A[gui/app.py<br>Tkinter 窗口] -->|文件列表 + 页数 + 目录| B[core/merger.py<br>merge 核心逻辑]
    B --> C[PyMuPDF<br>打开/校验源 PDF]
    C --> D[排版引擎<br>页数均匀分配 + 因子对网格选择]
    D --> E[A4 纵向画布<br>show_pdf_page 等比居中放置]
    E --> F[输出<br>m合n-date.pdf -> 桌面]
    F --> G[GUI 状态提示<br>打开所在文件夹]
```

分层设计：`core` 为纯函数库（无 GUI 依赖，可独立单测），`gui` 只做输入收集与结果展示，二者通过 `merge(file_paths, target_pages, output_dir)` 一个函数解耦，便于后续扩展 CLI 模式或打包分发。

核心算法：

- **页数分配**：`_distribute(T, n)`——总页数 T 尽量均匀拆到 n 页（前 `T % n` 页多放一张）
- **智能布局**：`_choose_layout(k, avg_aspect)`——枚举恰好占满的因子对（含转置），结合该页源页面平均宽高比计算等比缩放后的纸面利用率，默认取"最大列数 ≤ √k"保证对称，仅当转置布局利用率 ≥ 1.8 倍（极端宽高比）时改选
- **可靠性**：加密/损坏 PDF 校验、先写临时文件再原子重命名、重名自动追加序号

## 目录结构

```
pdf_merger.py        程序入口
core/merger.py       核心合并逻辑（网格排版、命名、桌面路径）
gui/app.py           Tkinter 窗口（拖拽、文件列表、页数输入）
requirements.txt     依赖（PyMuPDF、tkinterdnd2）
run.bat              一键运行（源码方式）
build_exe.bat        一键打包 exe（PyInstaller）
```

## 打包成 exe（免 Python 环境）

双击 `build_exe.bat`，完成后 exe 位于 `dist\发票PDF合并工具.exe`（单文件约 33MB），
可复制到任意 Windows 电脑双击使用，无需安装 Python。
